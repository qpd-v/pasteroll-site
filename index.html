Pasteroll

A clipboard history you scroll with the mouse wheel. Press Ctrl Shift and middle-click anywhere, scroll to an earlier clip, and click where it should go. It is encrypted on your computer, with no account and no cloud.

Download Source on GitHub

Windows 10/11 and Linux (X11; experimental GNOME 46 Wayland). Free and open source. Public beta: Windows 0.1.0-beta.6, Linux 0.1.0-beta.4.

Features

Carousel

Scroll your clipboard history without leaving what you are doing. One notch moves one clip; click into the note where it should land.

  • Every clip stays one gesture away, with no window switching.
  • The carousel closes as soon as you choose where the clip goes.

Expanded viewer

Expand any clip into a large reader. Long text scrolls smoothly, and the find bar jumps straight to the words you need.

  • Ctrl+F finds a word; F3 moves to the next match without losing your place.
  • The match count stays visible while you read.
  • Circle image areas for local OCR; copied text appears in your history.

Advanced Image Paste

Ctrl+click the desktop or any window with an image chosen and it opens in the editor with a live preview. Round the corners, tune the radius, add a shadow, then save a fresh PNG or paste it right there.

  • Rounded corners with a live radius control.
  • Drop shadow and transparent corners, saved as a fresh PNG on the Desktop.
  • In a window, paste the picture itself, the saved file's path, or just its file name (Windows).

Also

Encrypted per clip
Every clip is sealed before it is written, including when it was copied and from which program.
Two looks
Complete shows everything. No Bloat shows only the current clip, and the search bar and tools appear when you use them. Switch from the tray menu or Settings (Windows).
Recycle bin
Deleted clips come back with Ctrl+Z, or from the bin, for 30 days. Shift+Delete removes for good.
Terminal safe
Pasting several lines into a terminal asks for a second Enter first.
Skips password managers
Copies marked sensitive are never recorded, and you can exclude any program by name.
Images and files
Pictures and file lists are kept alongside text, with fast cached previews.
Size and key
Make the carousel 50 to 200 percent, and choose which key opens the image editor.

Privacy

A clipboard holds some of the most sensitive things on a computer, so Pasteroll keeps it there. There is no account, no sync and no analytics, and nothing is ever sent anywhere. History lives in a database on your own disk.

At rest
Each clip encrypted with XChaCha20-Poly1305
Network
None. Nothing is sent anywhere
Accounts
None
Source
Open, MIT or Apache-2.0

"Windows protected your PC"

The beta is not code-signed yet, so SmartScreen warns about new programs. Check the checksum below, then choose More info, Run anyway. Some antivirus programs are also wary of anything that watches the clipboard, which a clipboard manager must. The source is there to read and build yourself.

Verify your download

Every release has a SHA256SUMS file. The value must match exactly.

# Windows
Get-FileHash .\pasteroll-0.1.0-beta.6-windows-x64-setup.exe -Algorithm SHA256
# Linux
sha256sum -c SHA256SUMS --ignore-missing

Install on Linux (X11)

tar xzf pasteroll-0.1.0-beta.4-linux-x86_64.tar.gz
cd pasteroll-0.1.0-beta.4-linux-x86_64
./install.sh
pasteroll run

For all users: sudo ./install.sh --system. On Debian/Ubuntu: sudo dpkg -i pasteroll_0.1.0-beta.4_amd64.deb. Autostart stays off unless you enable it.

Optional: tesseract-ocr for Extract text, zenity or kdialog for Save as.

FAQ

Is it free?

Yes. Pasteroll is open source under the MIT or Apache-2.0 licence, your choice.

Does it send my clipboard anywhere?

No. Nothing is ever sent anywhere: no account, no sync, no telemetry. Text recognition (Extract text) runs on your computer too.

Where is my history stored?

In a database on your disk, in %LOCALAPPDATA%\Pasteroll on Windows and ~/.local/share/pasteroll on Linux. A portable.txt beside the executable keeps data in an adjacent data folder instead. Every clip is encrypted before it is written.

Does it record passwords?

Copies that password managers mark as sensitive are skipped, and you can exclude any program by name in Settings. Even so, a clipboard history is a risk worth knowing about, which is why Pasteroll encrypts it and lets you set how much is kept and for how long.

Does it work on Wayland? On macOS?

Beta.4 offers experimental native Wayland support on GNOME 46 with a Pasteroll Shell companion. Mouse activation needs an optional administrator-enabled host helper; keyboard mode uses Ctrl+Shift+Space. Mixed-scale display, viewer and editor checks passed on one Pop!_OS setup. Further manual acceptance, including physical mouse-helper, login/lock and suspend checks, is deferred. Other GNOME versions and Wayland desktops are not supported; use an X11 session for the standard Linux packages. There is no macOS version.

How do I uninstall it?

For Windows Setup installs, use Settings > Apps > Pasteroll. History is kept unless you choose to delete it. For a Linux archive install, use ./install.sh --uninstall, or sudo ./install.sh --system --uninstall for a system install. Remove the Debian package with sudo dpkg -r pasteroll; its history and settings stay on disk. Quit a portable copy before removing its extracted folder.
