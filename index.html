Pasteroll

A clipboard history you scroll with the mouse wheel. Press Ctrl Shift and middle-click anywhere, scroll to an earlier clip, and click where it should go. It is encrypted on your computer, with no account and no cloud.

Download Source on GitHub

Windows 10/11 and Linux (X11). Free and open source. Public beta 0.1.0.

How it works

One gesture opens it. From there you can do three things.

Ctrl+Shift+ Middle
click

Opens the carousel at your pointer, over whatever you are working in.

Paste

Scroll

Scroll to the clip you want, then simply click into the target window or input box (or press Enter) to paste. Select part of the text first to paste only that.

Expanded viewer

Click Expand on the active card to read long text, zoom into pictures and pull the text out of screenshots.

Image editor

With an image chosen, hold Ctrl while you click the desktop to crop, resize, add a shadow or outline and more before it is saved. A plain click saves it as it is.

Features

Carousel

Scroll your history where you are working, with nothing to switch to. Type to search (file names too), filter by text, images, documents and more, and pin the clips you want to keep.

  • Partial paste: double-click a word or drag across text, then paste only that.
  • Filters you define yourself, and pinned clips that are never removed automatically.

Expanded viewer

Any clip grows into a large window. Long text scrolls and searches, pictures zoom and pan, and Extract text reads the words in a screenshot. The recognition runs on your computer.

  • Previous and next without losing your place in the carousel.
  • Save as, Info, copy a selection, fullscreen.

Advanced Image Paste

Ctrl+click the desktop with an image chosen and it opens in an editor with a live preview. The original clip is never changed, and you can save your usual settings as presets.

  • Crop, resize, rotate and flip.
  • Outline, rounded corners, drop shadow and padding.
  • Remove or replace a plain background.
  • Save as PNG, JPG, WebP or BMP, wherever you like.

Also

Encrypted per clip
Every clip is sealed before it is written, including when it was copied and from which program.
Recycle bin
Deleted clips come back with Ctrl+Z, or from the bin, for 30 days. Shift+Delete removes for good.
Terminal safe
Pasting several lines into a terminal asks for a second Enter first.
Skips password managers
Copies marked sensitive are never recorded, and you can exclude any program by name.
Images and files
Pictures and file lists are kept alongside text, with fast cached previews.
Size and key
Make the carousel 50 to 200 percent, and choose which key opens the image editor.

Privacy

A clipboard holds some of the most sensitive things on a computer, so Pasteroll keeps it there. There is no account, no sync and no analytics, and nothing is ever sent anywhere. History lives in a database on your own disk.

At rest
Each clip encrypted with XChaCha20-Poly1305
Network
None. Nothing is sent anywhere
Accounts
None
Source
Open, MIT or Apache-2.0

"Windows protected your PC"

The beta is not code-signed yet, so SmartScreen warns about new programs. Check the checksum below, then choose More info, Run anyway. Some antivirus programs are also wary of anything that watches the clipboard, which a clipboard manager must. The source is there to read and build yourself.

Verify your download

Every release has a SHA256SUMS file. The value must match exactly.

# Windows
Get-FileHash .\pasteroll-windows-x64.zip -Algorithm SHA256
# Linux
sha256sum -c SHA256SUMS --ignore-missing

Install on Linux

tar xzf pasteroll-linux-x86_64.tar.gz
cd pasteroll-linux-x86_64
./pasteroll install
pasteroll run

Optional: tesseract-ocr for Extract text, zenity or kdialog for Save as.

FAQ

Is it free?

Yes. Pasteroll is open source under the MIT or Apache-2.0 licence, your choice.

Does it send my clipboard anywhere?

No. Nothing is ever sent anywhere: no account, no sync, no telemetry. Text recognition (Extract text) runs on your computer too.

Where is my history stored?

In a database on your disk, in %LOCALAPPDATA%\Pasteroll on Windows and ~/.local/share/pasteroll on Linux. Every clip is encrypted before it is written.

Does it record passwords?

Copies that password managers mark as sensitive are skipped, and you can exclude any program by name in Settings. Even so, a clipboard history is a risk worth knowing about, which is why Pasteroll encrypts it and lets you set how much is kept and for how long.

Does it work on Wayland? On macOS?

Not yet. Linux needs an X11 session (Ubuntu and Fedora offer one at the login screen). There is no macOS version.

How do I uninstall it?

Run pasteroll uninstall. Add --remove-data --yes to delete the history and its keys as well.
