Three steps from opening the carousel to pasting a clip

The newest copy is first in the list.

  1. 01

    Ctrl+Shift+middle-click brings the history up

    The carousel appears over the window you are using. On GNOME 46 Wayland, use the companion shortcut instead.

  2. 02

    Wheel or arrows move through clips; typing searches them

    Choose a media type from the filter when the list gets long.

  3. 03

    Clicking a destination pastes the clip

    To paste only part of a text clip, select that part in the preview first.

GNOME 46 Wayland uses the companion shortcut or the optional host helper. Read the GNOME setup steps.

Several text clips can become one paste

Join them with new lines, spaces, commas, tabs or a list. Images open in the editor for crop, background and drawing changes.

Multi-paste and image editing →

Clips and their encryption key stay in your user data folder

Each clip is encrypted before it reaches disk. Pasteroll has no account, sync or analytics. The Windows update check is off until you enable it, and an update downloads only after you confirm. The MCP agent brain is also opt-in and shares only selected rolls; a harness reading them may send that content to its model provider.
