Clips stay encrypted on disk. A coding harness reads only shared rolls.

Pasteroll has no account and no analytics; nothing syncs the history. The optional Windows update check and the agent brain stay off until you enable them.

Clips, settings and the encryption key share one folder.

A recorded clip holds text, a file list or a picture, plus limited metadata such as the copy time and source program. The same folder also holds settings, favorite colors and image-editor presets.

How Windows and Linux protect the encryption key

Each clip is encrypted with XChaCha20-Poly1305 before it is written. The database and key sit in a private per-user data folder.

Who can still read the history

On Linux, file permissions are the only protection around the key file, so use full-disk encryption. Windows protects the key with the account-bound key store. Either way, code already running as your user can reach the same data you can. Encryption at rest does not stop malware in an active session.

What GitHub sees during an update check

With the check enabled, Pasteroll contacts GitHub. GitHub can see your IP address and Pasteroll version. Pasteroll does not send clipboard history. An update downloads only after you choose Download and install and confirm it. Linux packages have no automatic updater.

A coding harness may send a shared roll to its model provider.

The agent brain is off by default. When enabled, a coding harness starts a local MCP server and can read only the rolls you explicitly share. Pasteroll opens no port and sends nothing itself.

That transfer belongs to the harness, just as it would if you pasted the clip into the chat. Share only rolls you are comfortable giving to that provider. Images are off by default.

Treat clipboard text as untrusted data. The MCP server labels it that way, and an agent should not follow instructions found inside a clip.

Stopping capture or deleting a stored clip

Pause recording from the tray or panel menu. Exclude programs by executable name. Copies that password managers mark as sensitive are skipped. You can set history limits, clear the history while keeping favorites, and delete individual clips permanently.
