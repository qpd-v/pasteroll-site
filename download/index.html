Current

Adds a Start menu shortcut, offers a desktop shortcut, and uses the standard Windows uninstaller. Installing for every user requires UAC.

Windows SmartScreen

This beta is unsigned, so Windows may show a SmartScreen warning. Compare the SHA-256 value first. To continue, choose More info, then Run anyway. Clipboard and keyboard access can also make antivirus tools suspicious.

GNOME 46 only · experimental

GNOME 46 Wayland, with a companion and optional mouse helper

Experimental

The package contains the app, a GNOME Shell companion, and an optional host input helper that an administrator must enable. Mouse activation needs the helper. Keyboard mode uses CtrlShiftSpace.

Both the app and the companion need protocol 4

Other GNOME versions and Wayland compositors are not supported. Testing has not covered physical mouse-helper devices, login or lock screens, suspend, or mixed-DPI layouts. The GNOME .deb replaces the X11 package; they are alternatives.
