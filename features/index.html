What the carousel can do with a copied clip

The carousel opens over the window you are using with your newest clips. Search by text or file name, keep favorite tiles, join text or file clips, edit a picture, or let a coding agent read rolls you share.

The search matches clip text and file names

The carousel opens at the pointer with your newest clips. Turn the wheel, use the arrow keys, or type to search text and file names. Filter by Text, Document, Image, Video, Audio, Compressed or Favorites.

  • Open a long clip in the expanded viewer and use Find to jump to a word or phrase.
  • Double-click a word, then keep holding and drag to extend the selection. Double-click the clip header or blank space beneath its content to paste.
  • Circle an area of a picture for local OCR; extracted text returns to your history.

Favorite tiles above the list, rolls on either side of Main

Favorites stay until you remove them and appear as tiles above the list, with a preview and a color you choose.

  • Rolls are separate collections you move between from left to right; Main always holds the full history.
  • Drag the carousel by an empty margin, then pin it open with Ctrl+K while you work elsewhere.
  • No Bloat shows only the current clip while the keyboard features remain available.

Paste several images, or join text clips

Ctrl+click an inactive clip to select it together with the active clip. Or turn on Multi-paste with its button to start with no selection, then select the clips you want. Image clips paste as separate attachments or inline images. For text and file clips, paste a joined result with separators, list styles and ordering.

  • Ctrl+click starts Multi-paste with the active and clicked clips. The Multi-paste button starts empty; only selected clips are highlighted. Ctrl+Shift+click chooses a range. Image and text selections can be pasted together.
  • The joined result enters history as one clip with a badge showing how many clips it contains.
  • Image batches support up to 32 images and 24 MB. Ctrl+E opens Attachments / Inline images and order options. Select images separately from text/file clips; receiving-app support varies.

Ctrl+click the current image to edit it

With Multi-paste off and no selection, Ctrl+click the current image clip to open Advanced Image Paste, or Ctrl+click an inactive image to open a tabbed editor for all selected images. To choose the destination before editing, select an image and Ctrl+click the desktop or a window.

  • Crop, resize, rotate, flip, round corners, add a shadow, outline or padding, and remove or fill the background.
  • Draw with a pen, brush, circle, arrow or text, with undo and redo. Zoom with the mouse wheel, or the zoom-out, zoom-in, Fit and Actual size icons. The percentage is a separate read-only display; Alt+drag pans while cropping or drawing.
  • Save a fresh PNG, JPG, WebP or BMP, or paste the picture, its path or its file name. Batch tabs can save every edited image and paste all paths.

A local, read-only MCP server for the rolls you share

The optional agent brain is a local, read-only MCP server. Claude Code, Codex and OpenCode can each start their own copy against the same encrypted history. No port is opened and Pasteroll sends nothing itself.

  • Turn it on with pasteroll brain on and share a roll with pasteroll brain add Work.
  • The available tools list, read and search shared rolls; none can write, copy, paste or delete.
  • Images are off by default, request limits apply, and the brain stays off until you enable it.
  • A harness that reads a clip may send it to its model provider. Read the MCP privacy details.
