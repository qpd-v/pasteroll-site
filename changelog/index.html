2026-11-08

0.1.0-beta.20

WindowsLinux
  • Ctrl+click an image clip in the carousel to open Advanced Image Paste.
  • Ctrl+click text and file clips still chooses them for Multi-paste.
  • Windows update downloads retry transient GitHub gateway failures.
  • Existing history, keys, settings and rolls are kept.

2026-11-08

0.1.0-beta.19

WindowsLinux
