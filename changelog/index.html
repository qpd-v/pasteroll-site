Changelog

Every change to Pasteroll, generated from its commit history on GitHub.

  1. October 21, 2026

    Add the No Bloat look and image editing in any window (Windows beta.5)

    6eabdbe
    • Add a No Bloat look for the carousel: only the current clip in a smaller window, with no clip list and no card buttons. Every feature still works from the keyboard and its controls appear when used: the search bar while you type, the filter menu on Tab, a star on pinned clips, Ctrl+E for the expanded viewer.
    • Switch between Complete and No Bloat from the Windows tray menu (no restart) or Settings; saved as [appearance] mode in config.toml.
    • Advanced Image Paste now opens on any window, not only the desktop. A new Paste as choice pastes the edited picture, the saved file's path, or its file name; terminals default to the path.
    • Check the destination window, the pasted text and the folder before the editor closes: refuse a window that needs more rights, a window that lost the foreground, relative folders, and path characters a terminal would act on.
    • Windows-only release: version 0.1.0-beta.5, with Linux staying on beta.4.

    Fix GNOME mixed-scale rendering and prepare beta.4 release

    0fe94d4
    • Separate display coordinates from UI density and transfer large viewers without resampling.
    • Verify transparent Linux icons and document deferred OCR quality and Linux interface parity.
    • Prepare Windows, X11 and experimental GNOME packages with explicit manual-testing limits.

  5. October 16, 2026

    Prepare beta.2 installers, portable mode, and release tooling

    ae21138

    Advanced Image Paste

    6f7c660

    Ctrl+click on the desktop with an image chosen (the key is a setting: Ctrl, Shift or Alt) opens an image editor instead of saving at once; a plain click still saves immediately.

    • The card animates into a modal editor window with a live preview: outline, resize, crop (handles, numbers, locked shapes), rounded corners, drop shadow, background remove/fill/replace, padding, any-angle rotate and flips, PNG/JPG/WebP/BMP output with quality
    • File name and folder choice, undo/redo, reset all, saved presets
    • The clip is never changed; the preview and the saved file apply the same adjustments to a reduced copy and to the whole picture
    • Windows and Linux: click modifier capture, modal clicks, folder chooser, presets file, settings entry

    Expanded viewer, recycle bin, and text extraction

    c85c05d
    • Expanded viewer: animated card-to-overlay with back and fullscreen, text/image viewing, zoom and pan, find, word wrap, info panel, save as, prev/next, and a bottom toolbar with a More menu
    • Recycle bin: delete sends clips to a 30-day bin; restore, undo, and Shift+Delete or Shift+click for permanent deletion with confirmation
    • Extract text from images with the OS text recognition (Windows.Media.Ocr; tesseract on Linux), entirely local
    • Sealed copy time and source app on new clips (store schema v5)
    • Crash notes in pasteroll.log (location only, never clip data)
    • seed --image option for test histories
