Changelog

Every change to Pasteroll, generated from its commit history on GitHub.

  1. October 28, 2026

    A new Settings window and multi-pastes kept in history (Windows beta.12)

    9c66078
    • The Settings window is redesigned: compact, in two columns, and it follows the Windows light or dark mode. Save and Cancel are no longer cut off on a small or high-scaling screen.
    • A multi-paste is kept in history as one clip, with a small badge showing how many clips went into it.
    • The Multi-paste button in the carousel is now an icon.
    • Windows-only release: version 0.1.0-beta.12, with Linux staying on beta.4.

    Multi-paste button, picture folder and choosing several clips (Windows beta.11)

    65938ac
    • A Multi-paste button beside the filter: press it, click each clip you want (Shift+click for a range), then click where they should go. They are pasted one per line in the order you clicked.
    • Ctrl+click and Ctrl+Shift+click choose clips too; Ctrl+C or right-click Copy puts them on the clipboard without pasting.
    • Settings has a "Save pictures in this folder" choice for Paste Path and the image editor.
    • Windows-only release: version 0.1.0-beta.11, with Linux staying on beta.4.
  2. October 24, 2026

    Do not mention a local-only notes file in the changelog

    29eaaa9

    Linux code catches up: picture folder, several clips, Complete and No Bloat

    64891e4
    • Linux Settings has the picture folder row, and Ctrl+click, Ctrl+Shift+click, Ctrl+C and right-click Copy work on X11.
    • Complete and No Bloat can be chosen from the Linux tray menu and with config set mode; the GNOME Wayland window size follows it.
    • The Desktop folder is read from the XDG config folder; a relative or home-folder value is ignored.
    • Adds an isolated X11 test for these (a private screen, run under WSL).
    • Not released: Linux stays on beta.4, and none of this has run on a real desktop or GNOME Wayland yet.

    Ask again when the chosen clips change, copy what is highlighted, keep new picture folders private

    33a17d8
    • Choosing or un-choosing a clip, or clearing the choice, now withdraws the "several lines into a terminal" warning, so Enter asks again instead of pasting what was not warned about.
    • Ctrl+C with nothing chosen copies just the highlighted part of the clip when there is one.
    • Clips that cannot be read are counted apart from pictures when several are joined.
    • A picture folder the program creates from Settings is private to the user on Linux.

    Choose a folder for saved pictures, and paste several clips at once

    7eafebf
    • New Settings option for the folder where Paste Path and the image editor save pictures (the Desktop is still the default).
    • In the Complete carousel, Ctrl+click chooses clips and Ctrl+Shift+click chooses a range. Clicking the target window pastes them one per line.
    • Ctrl+C, or right-click then Copy, puts the chosen clips on the clipboard without pasting.
  3. October 22, 2026

    Record a real beta.9 to beta.10 update in the release notes

    41817e2
    • The release notes now say that a real beta.9 copy was updated to beta.10 from GitHub, and that this did not use the signed note.

    Sign which version is newest, add a Check now button and Skip this version (Windows beta.10)

    be5283e
    • The update check now learns the newest version from a short note that is signed with the Pasteroll release key, instead of trusting GitHub's list of releases. An older genuine note served again is ignored.
    • Settings has a "Check for updates now" button and shows how long ago the last check was.
    • The install window shows what is new in the version and has a "Skip this version" button.
    • If an update's installer fails or crashes, the previous Pasteroll is started again and says so; after a successful update Pasteroll says which version you now have.
    • More tests of the downloader (slow, endless, partial, sign-in and compressed answers) and some unused code removed.
    • Windows-only release: version 0.1.0-beta.10, with Linux staying on beta.4.

    Add Download and install for updates, with signed releases (Windows beta.9)

    725d226
    • When the update check finds a newer version, the tray menu and the notification now offer "Download and install". Nothing is downloaded until you click it and confirm.
    • The update is downloaded from GitHub and checked against the Pasteroll release key's signature and its checksum before anything runs; a file that fails is deleted.
    • Copies installed with Setup update silently and start again; portable copies replace their own program file.
    • Copies installed for all users ask Windows for administrator permission and are updated from a folder only administrators can open.
    • Releases now carry a signed update manifest and a bare program file; SECURITY.md and PRIVACY.md describe exactly what is downloaded, how it is trusted and what is not protected.
    • Settings now says the update check asks GitHub and that you choose whether to install.
    • Windows-only release: version 0.1.0-beta.9, with Linux staying on beta.4.
  4. October 21, 2026

    Fix the Settings window not showing your update-check answer (Windows beta.8)

    6cdd9c4
    • Fix the "Check for updates once a day" box in Settings staying empty after you answered the one-time update question while Settings was open. The open window now follows a choice made elsewhere within a second, so what you see is what was saved.
    • The one-time update question now waits until Settings is closed instead of appearing on top of it.
    • Windows-only release: version 0.1.0-beta.8, with Linux staying on beta.4.

    Add an optional update check, off until you say yes (Windows beta.7)

    09da79d
    • Add an optional update check. The first time you run this version Pasteroll asks once whether it may check for updates; the default button is Never check, and closing the window decides nothing. Settings has a checkbox for it.
    • When it is on, about once a day Pasteroll asks GitHub for the list of releases and tells you if a newer version exists, with a notification and a tray menu entry that open its release page. It never downloads or installs anything.
    • Check by hand from the tray menu (Check for updates now) or with pasteroll update-check. With the check off, Pasteroll makes no network request at all.
    • Describe exactly what is sent and how the reply is handled in PRIVACY.md and SECURITY.md, and stop saying that nothing is ever sent anywhere: your clipboard still never leaves your computer.
    • Uninstalling with delete data now also removes the update check's state file.
    • Windows-only release: version 0.1.0-beta.7, with Linux staying on beta.4.

    Fix Advanced Image Paste in Windows Terminal and PowerShell (Windows beta.6)

    09f5a14
    • Fix Advanced Image Paste never opening in Windows Terminal, and so in PowerShell, Claude Code and opencode. Windows Terminal reports its whole window as a title bar, so the click was refused as not on a client area. A click is now accepted when it lies inside the window's client rectangle; a standard title bar, borders and caption buttons are still refused.
    • A plain click-to-paste into Windows Terminal was refused the same way and works now too.
    • Open the editor even when Ctrl is still held a second after the click. A click that only opens the editor types nothing yet, so it no longer waits for every key to be released.
    • Add real-window self-tests for both cases, including a real Windows Terminal window.
    • Windows-only release: version 0.1.0-beta.6, with Linux staying on beta.4.

    Add the No Bloat look and image editing in any window (Windows beta.5)

    6eabdbe
    • Add a No Bloat look for the carousel: only the current clip in a smaller window, with no clip list and no card buttons. Every feature still works from the keyboard and its controls appear when used: the search bar while you type, the filter menu on Tab, a star on pinned clips, Ctrl+E for the expanded viewer.
    • Switch between Complete and No Bloat from the Windows tray menu (no restart) or Settings; saved as [appearance] mode in config.toml.
    • Advanced Image Paste now opens on any window, not only the desktop. A new Paste as choice pastes the edited picture, the saved file's path, or its file name; terminals default to the path.
    • Check the destination window, the pasted text and the folder before the editor closes: refuse a window that needs more rights, a window that lost the foreground, relative folders, and path characters a terminal would act on.
    • Windows-only release: version 0.1.0-beta.5, with Linux staying on beta.4.

    Advanced Image Paste

    6f7c660

    Ctrl+click on the desktop with an image chosen (the key is a setting: Ctrl, Shift or Alt) opens an image editor instead of saving at once; a plain click still saves immediately.

    • The card animates into a modal editor window with a live preview: outline, resize, crop (handles, numbers, locked shapes), rounded corners, drop shadow, background remove/fill/replace, padding, any-angle rotate and flips, PNG/JPG/WebP/BMP output with quality
    • File name and folder choice, undo/redo, reset all, saved presets
    • The clip is never changed; the preview and the saved file apply the same adjustments to a reduced copy and to the whole picture
    • Windows and Linux: click modifier capture, modal clicks, folder chooser, presets file, settings entry

    Expanded viewer, recycle bin, and text extraction

    c85c05d
    • Expanded viewer: animated card-to-overlay with back and fullscreen, text/image viewing, zoom and pan, find, word wrap, info panel, save as, prev/next, and a bottom toolbar with a More menu
    • Recycle bin: delete sends clips to a 30-day bin; restore, undo, and Shift+Delete or Shift+click for permanent deletion with confirmation
    • Extract text from images with the OS text recognition (Windows.Media.Ocr; tesseract on Linux), entirely local
    • Sealed copy time and source app on new clips (store schema v5)
    • Crash notes in pasteroll.log (location only, never clip data)
    • seed --image option for test histories
